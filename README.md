# Portable Scripts

Colección de scripts de shell útiles para automatizar tareas comunes en sistemas Unix/Linux.

## Scripts Disponibles

| Script | Descripción |
|--------|-------------|
| `flog.sh` | Sistema de logging estructurado para registrar eventos |
| `fnc_is_sourced.sh` | Detecta si un script fue ejecutado con `source` o directamente |
| `lk.sh` | Buscador de archivos con listado detallado |
